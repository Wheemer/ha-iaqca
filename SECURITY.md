# Security Policy

## Supported Versions

Security fixes are made on the current default branch, `dev`, and released
versions when applicable.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through
[GitHub Private Vulnerability Reporting](https://github.com/Wheemer/ha-iaqca/security/advisories/new).

Do not open a public issue for a suspected vulnerability. Include affected
versions, reproduction steps, potential impact, and any proposed mitigation.
We will acknowledge the report, investigate it privately, and coordinate a
fix and disclosure when appropriate.
